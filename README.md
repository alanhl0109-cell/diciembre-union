# Diciembre 2026: cuánto voy a recibir

Calculadora para el personal de la Unión de Crédito: suma las semanas de descanso que se pagan por adelantado, el aguinaldo y la PTU de nómina y lo que se da por fuera.

Ábrela aquí: https://alanhl0109-cell.github.io/diciembre-union/

- Funciona en computadora y celular, sin instalar nada ni crear cuentas.
- Es una página estática: no tiene servidor, base de datos, claves ni APIs.
- Lo que cada persona captura se queda solo en su propio navegador; no se envía a ningún lado.
- Cálculos con parámetros fiscales 2026 (Anexo 8 RMF, UMA y subsidio para el empleo). Es una estimación de apoyo; mandan los recibos timbrados.
